The full native suite reports **486 total: 483 passed, 2 failed, 1 skipped**.
The separate focused `PlatformStorageTests` run reproduces both failures:
**6 total, 4 passed, 2 failed**. These runs executed outside the tool sandbox;
the failures below are not the earlier sandbox IPC failures.

| Test | Observed Windows result |
|---|---|

The promised successful replacement is not established. |
| `Failed_publication_cleans_staging_and_path_keys_cannot_escape` | Publishing over the authored directory named `blocked.oc2data` throws `UnauthorizedAccessException`; the test at line 46 requires exactly `IOException`. The normal UI import/export path passing does not close either failure. Fix and
rerun these gates before accepting Windows storage. Preserve both original logs
when recording later results.

The skipped test is
`NativeAudioTests.Native_output_completion_loop_cancellation_and_replacement`.
It requires `OC2_TEST_NATIVE_AUDIO=1` and an isolated output sink; no such sink
was supplied. The offline graph checks do not establish speaker output.

Native AOT publication exits successfully but ILC emits two diagnostics for
Avalonia Win32 DirectComposition `CreateTargetForHwnd` callbacks: the
`UnmanagedCallersOnly` methods have non-blittable Boolean parameters and will
throw if invoked. Startup and the bounded GPU interaction below passed; that
does not establish those callback paths as safe.
