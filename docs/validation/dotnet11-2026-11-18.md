# .NET 11 and SkiaSharp 4 validation — 2026-11-18

The uncommitted upgrade passed these checks on Linux x64 with .NET SDK
**11.0.100**, runtime **11.0.0**, C# **15.0**, Python 3.14.4 and Chromium
151.0.7922.34 (Playwright 1.58.2). Avalonia remains at 12.1.6; both desktop and
browser resolve SkiaSharp **4.156.1**, HarfBuzzSharp **14.4.0.101** and matching
native assets through central transitive pinning. The browser uses the pinned
.NET 11 workload's Emscripten 6.0.2 assets.

The desktop's published Linux SkiaSharp and HarfBuzzSharp binaries match the
upgraded NuGet archives. All 31 production package archive pins were verified
against locked content hashes and NuGet signatures; runtime archive pins were
refreshed for .NET 11. The dependency audit found only the intended SDK and
graphics version changes.

Collector smoke runs use one measured sample per workload. They do not replace
the earlier [performance studies](../performance/README.md) or establish current
performance acceptance. The native warmed-report validator skips its one
WASM-only memory check; the browser validator passes that check.
